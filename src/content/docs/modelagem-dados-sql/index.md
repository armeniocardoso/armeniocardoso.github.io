Os dados estão presentes em praticamente todos os sistemas de software. Aplicações comerciais, sistemas bancários, lojas virtuais e plataformas digitais precisam armazenar, organizar e recuperar informações de maneira eficiente e confiável.

Para trabalhar com dados, não basta conhecer os comandos de uma linguagem de consulta. É importante compreender como as informações são organizadas, como se relacionam e quais regras garantem a consistência dos dados.

Nesta seção, vamos estudar os fundamentos da **modelagem de dados relacionais** e da linguagem **SQL (Structured Query Language)**, utilizada para criar estruturas, manipular informações e consultar bancos de dados relacionais.

## O que você vai aprender

Ao longo dos conteúdos, vamos explorar:

- **Fundamentos de bancos de dados:** conceitos essenciais para compreender o armazenamento e a organização das informações.
- **Modelagem de dados:** identificação de entidades, atributos e relacionamentos que representam as informações de um domínio.
- **Modelo relacional:** organização dos dados em tabelas, utilização de chaves primárias e estrangeiras e compreensão dos relacionamentos.
- **SQL:** comandos para criar estruturas, inserir, atualizar, excluir e consultar dados.
- **Consultas relacionais:** utilização de filtros, ordenação, agrupamentos e junções entre tabelas.

## Por onde começar?

Minha sugestão é seguir uma sequência que começa pela compreensão de como os dados são organizados e avança gradualmente para a construção de consultas SQL.

Afinal, conhecer a sintaxe de uma linguagem é importante, mas compreender o problema que estamos tentando resolver é ainda mais importante.
