Desenvolver aplicações para a Web envolve muito mais do que escrever código HTML, CSS e JavaScript. É preciso compreender como as diferentes tecnologias trabalham juntas para construir interfaces, processar informações e oferecer experiências eficientes aos usuários.

Nesta seção, vamos explorar os principais conceitos, ferramentas e frameworks utilizados no desenvolvimento de aplicações web, sempre procurando relacionar os fundamentos teóricos com exemplos práticos.

## O que você vai encontrar aqui?

### React

O React é uma biblioteca JavaScript utilizada para construir interfaces de usuário por meio de componentes reutilizáveis.

Vamos explorar seus fundamentos, a organização de aplicações, o gerenciamento de estado, os hooks e as práticas necessárias para desenvolver interfaces modernas.

### Next.js

O Next.js é um framework construído sobre o React que amplia suas possibilidades, oferecendo recursos como renderização no servidor, geração de páginas estáticas, roteamento e otimizações de desempenho.

Começaremos com uma introdução aos conceitos fundamentais e avançaremos para o desenvolvimento de aplicações utilizando o App Router.

## Aprendendo na prática

A proposta da CulturaTEC é aprender construindo. Por isso, os conteúdos desta seção procuram combinar explicações conceituais, exemplos de código e projetos que ajudem a compreender como as tecnologias são utilizadas no desenvolvimento de aplicações reais.

Mais importante do que conhecer uma ferramenta é entender os problemas que ela resolve e saber quando utilizá-la.
