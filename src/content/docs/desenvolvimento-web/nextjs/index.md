O React oferece os recursos necessários para construir interfaces de usuário, mas desenvolver uma aplicação web completa envolve outras preocupações: roteamento, renderização das páginas, integração com serviços, otimização de desempenho e mecanismos de entrega de conteúdo.

É nesse contexto que entra o **Next.js**.

Construído sobre o React, o Next.js é um framework que reúne recursos e convenções para facilitar o desenvolvimento de aplicações web. Com ele, podemos explorar diferentes estratégias de renderização, organizar a navegação da aplicação e aproveitar otimizações que seriam trabalhosas de implementar manualmente.

Nesta seção, vamos conhecer o framework e aprender a utilizá-lo na construção de aplicações práticas.

## O que você vai aprender?

### Introdução ao Next.js

Vamos começar entendendo por que o Next.js surgiu, quais limitações do desenvolvimento tradicional com React ele procura resolver e quais são seus principais recursos.

Entre os conceitos abordados estão:

- React e Next.js: biblioteca e framework.
- Renderização no cliente (CSR).
- Renderização no servidor (SSR).
- Geração de páginas estáticas (SSG).
- Incremental Static Regeneration (ISR).
- Roteamento e organização de aplicações.
- Hidratação e otimização de desempenho.

### Next.js com App Router

O App Router é o sistema de roteamento recomendado pelo Next.js para o desenvolvimento de novas aplicações.

Nessa etapa, vamos avançar para a implementação, explorando recursos como:

- Estrutura de diretórios e roteamento.
- Pages e layouts.
- Server Components e Client Components.
- Busca de dados e integração com APIs.
- Renderização e estratégias de cache.
- Navegação e componentes de interface.

## Next.js e o ecossistema React

O Next.js não substitui o React: ele utiliza a biblioteca como base e acrescenta recursos e convenções para estruturar aplicações completas.

Por isso, conhecer os fundamentos do React é um importante ponto de partida para aproveitar melhor o framework.

Se você ainda não estudou esses conceitos, consulte também a seção [React](../react/).
