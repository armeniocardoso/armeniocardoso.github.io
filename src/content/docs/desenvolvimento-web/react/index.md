O React é uma biblioteca JavaScript utilizada para construir interfaces de usuário. Criado pelo Facebook (atual Meta), tornou-se uma das principais tecnologias utilizadas no desenvolvimento de aplicações web modernas.

Sua proposta é organizar a interface em componentes reutilizáveis, permitindo dividir uma aplicação em partes menores, independentes e mais fáceis de desenvolver e manter.

Mas, afinal, como funciona essa abordagem? E por que tantas equipes utilizam React em seus projetos?

Nesta seção, vamos conhecer os fundamentos da biblioteca e aprender a utilizá-la na construção de interfaces.

## O que você vai aprender?

### Fundamentos do React

Antes de desenvolver aplicações completas, precisamos compreender os conceitos que sustentam o React:

- Componentes e composição de interfaces.
- JSX e expressões JavaScript.
- Props e comunicação entre componentes.
- Estado e atualização da interface.
- Eventos e tratamento de interações.
- Hooks e gerenciamento do ciclo de vida dos componentes.

### Desenvolvimento de aplicações

Depois de conhecer os fundamentos, vamos avançar para a construção de aplicações, explorando:

- Organização e estrutura de projetos.
- Gerenciamento de estado.
- Consumo de APIs e integração com serviços.
- Formulários e validação de dados.
- Navegação entre páginas.
- Boas práticas de desenvolvimento.

## React e seu ecossistema

React é uma biblioteca, não um framework completo. Por isso, seu ecossistema inclui ferramentas e frameworks que ampliam suas funcionalidades.

Um exemplo importante é o Next.js, que utiliza React como base e oferece recursos adicionais para o desenvolvimento de aplicações web, como diferentes estratégias de renderização e roteamento.

Se você deseja conhecer essa abordagem, consulte também a seção [Next.js](../nextjs/).

## Aprendendo na prática

Na CulturaTEC, a melhor maneira de aprender uma tecnologia é utilizá-la para resolver problemas concretos.

Por isso, os conteúdos desta seção procuram combinar explicações conceituais, exemplos de código e exercícios práticos. O objetivo não é apenas aprender a utilizar os recursos do React, mas compreender como construir interfaces organizadas, reutilizáveis e fáceis de evoluir.
