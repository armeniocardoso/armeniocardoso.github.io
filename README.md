# CulturaTec

Site de documentação e materiais de estudo de engenharia de software, arquitetura e desenvolvimento.

## Tecnologias

- Astro
- Starlight
- Vite

## Estrutura principal

- `src/content/docs/` — conteúdo em Markdown/MDX
- `src/assets/` — imagens e ativos estáticos
- `astro.config.mjs` — configuração do site e sidebar

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Publicação

Este projeto está configurado para publicar no GitHub Pages e usa a geração estática do Astro/Starlight.
